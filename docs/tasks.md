## Легенда

**Статусы (дорожки канбана):** Backlog — в очереди · To Do — взята в
ближайшую работу · In Progress — в работе прямо сейчас · Review — сделана,
проверяется/тестируется · Done — завершена.

**Приоритеты (MoSCoW):** Must — без этого MVP не работает и не соответствует
приказу · Should — важно, но MVP живёт без этого · Could — желательно, если
останется время.

**Этапы хакатона:** Dive — разобраться в задаче · Create — прототип,
архитектура, тесты · Impact — упаковка эффекта и защита.
