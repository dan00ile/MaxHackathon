# MaxHackathon

Бот приёмки актов МКД в MAX — председатель совета МКД принимает или
аргументированно отклоняет акт приёмки работ УК прямо в мессенджере MAX, в
срок и без юриста.

Проектная документация — в [`docs/`](docs):

- [`docs/idea.md`](docs/idea.md) — исходная идея, нормативное обоснование, разбор рисков
- [`docs/pitch-analysis.md`](docs/pitch-analysis.md) — PSW-разбор, impact, привязка к критериям жюри
- [`docs/requirements.md`](docs/requirements.md) — актуальные системные требования (MoSCoW, FR/NFR, модель данных)
- [`docs/requirements-changelog.md`](docs/requirements-changelog.md) — история правок требований и почему
- [`docs/tasks.md`](docs/tasks.md) — снэпшот канбан-доски задач
- [`docs/original/`](docs/original) — исходные PDF/XLSX от команды
